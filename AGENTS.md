# Project instructions

Read the portfolio `AGENTS.md` and the reference library's canonical
`START_HERE.md` before changing this project.

Read `project-manifest.toml`, `docs/FEASIBILITY.md`, the shared findings
registry, and the shared PSXRecomp source pin before building or diagnosing.

This repository is a source-only owned-input setup host. Never commit or
upload a disc image, retail BIOS, generated retail code, save, Ghidra project,
capture, dump, private path, or credential. Keep generated and local evidence
in the ignored directories.

Keep Leon and Claire as separate source snapshots until the framework has a
qualified multi-program lifecycle. Leon uses main. Claire uses the immutable
program/claire tag; see docs/BRANCH_ARCHIVE.md. Keep `func_override` and partial
decompilation outside the stable source lane. Do not publish a release or
submit a RetComM entry without Alex's later authorization and manual test.
